# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/jk-neha/nehavardhinijk-portfolio.git
```

Move into the project

```bash
cd nehavardhinijk-portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
