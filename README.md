# Neha Vardhini J K – Portfolio

Vite + React. Content lives in `src/data.js`; layout in `src/App.jsx`; styles in `src/index.css`.

## Run
    npm install
    npm run dev        # local
    npm run build      # production build (deploy to Vercel)

## Before you deploy
1. Add your portrait as `public/photo.jpg` (a head-and-shoulders photo with space on the left works best; the page turns it black and white with the lavender glow). Until then a "NV" monogram shows.
2. Replace `public/Neha Vardhini J K Resume.pdf` with your latest resume.
3. Check the email in `src/data.js`.
